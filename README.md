# 🚀 SkillBridge AI - Production MVP CS Career Platform

**SkillBridge AI** is an AI-powered Career Guidance & Skill Engineering platform designed for Computer Science students and Software Engineering candidates. Built with **React 18**, **TypeScript**, **Tailwind CSS**, **Express.js**, **Google Gemini AI (via @google/genai)**, and **Firebase Authentication & Cloud Firestore**.

---

## 🔥 Key Active Features

### 1. 🎯 Dynamic AI Career Skill Assessment
- Role-specific technical diagnostic matrix dynamically generated by **Google Gemini AI**.
- Evaluates student proficiency across Programming Languages, Frameworks, Databases, Tools, and Soft Skills for any engineering target role (e.g. *Full Stack Developer*, *Backend Engineer*, *AI Engineer*, or custom roles).
- Calculates a dynamic **Career Readiness Score (0-100%)** persisted directly in Firebase Firestore.

### 2. 🗺️ Assessment-Gated 12-Week AI Career Roadmap
- Generates a customized 12-week step-by-step milestone learning roadmap based on candidate skill gaps.
- Protected by an **Assessment Gate**: prompts users to complete their skill diagnostic before unlocking their roadmap.
- Interactive weekly tasks, difficulty ratings, and mini-project checkpoints with progress tracking synced to Firestore.

### 3. 📄 AI Resume Builder with ATS PDF & TXT Export
- Auto pre-fills personal & academic details directly from the candidate's profile.
- **Dynamic AI Enhancer**: Rewrites professional summaries and experience bullet points into high-impact action-verb statements using Gemini AI.
- Multi-bullet point controls for Work Experience and Academic Education.
- 4 ATS-friendly template presets (`ATS Executive`, `Modern`, `Developer Minimal`, `Creative Tech`) with 1-click **PDF Export** and **.TXT Download**.

### 4. 🎤 AI Mock Interview Coach & STAR Evaluator
- Realistic AI technical & behavioral interview simulator pre-configured to your target role.
- Choose between **5 Questions (Quick Practice Drill)** or **12 Questions (Standard Full Assessment)**.
- Voice dictation microphone support and live text-to-speech AI question reader.
- Detailed Recruiter Evaluation Report with STAR compliance, technical accuracy, communication scores, and downloadable PDF/TXT reports.

### 5. 🐙 GitHub Repository Analyzer
- Evaluates GitHub profile architecture, code quality, repo stars, and topic tags.
- Provides recruiter feedback and auto-generates high-impact resume bullet points for every project.

### 6. 💬 24/7 AI Career Mentor
- Interactive real-time career guidance chat powered by Gemini AI.
- Instant advice on technical stack choices, salary negotiation, system design concepts, and interview prep.

### 7. 🔒 Firebase Authentication & Cloud Firestore Database
- Secure Email & Password account creation, login, and password reset email flow.
- Per-user data isolation: candidate profiles, assessments, roadmaps, and resumes persist in Cloud Firestore collections (`users`, `assessments`, `roadmaps`, `resumes`).

---

## 🛠️ Technology Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Backend Server**: Node.js, Express.js
- **AI Intelligence**: Google Gemini API (`@google/genai` SDK with `gemini-flash-latest` model)
- **Database & Auth**: Firebase Authentication & Cloud Firestore
- **PDF Export**: html2canvas + jsPDF

## 🚀 Local Development Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Create a `.env.local` file in the project root:
```env
GEMINI_API_KEY=your_google_gemini_api_key
PORT=3000
```

### 3. Start Development Server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

## 🔐 Firebase Setup Notes

To enable real-time Cloud Firestore database persistence:
1. Ensure your Firebase project configuration is present in `firebase-applet-config.json`.
2. In **Firebase Console** -> **Firestore Database** -> **Rules**, publish:
   ```javascript
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /{document=**} {
         allow read, write: if true;
       }
     }
   }
   ```
